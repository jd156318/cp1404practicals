# CP1404 Practicals

This repository contains all my practical work for IT@JCU CP1404.

## Content

The practicals focus on IPO principle, functions, version control, files, exception handling, lists,
tuples, dictionaries, sets and classes.

Here's the [CP1404 Practicals instructions repo](https://github.com/CP1404/Practicals/tree/master) and the
[Programming Patterns page](https://github.com/CP1404/Starter/wiki/Programming-Patterns) for reference.

## Tips for clean code

- Be intentional in naming - use the imperative mood
- Always use the *Don't Repeat Yourself* principle
- Peer review can be very effective to clean up code
